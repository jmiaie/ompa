# README infographics

Generated by `make_assets.py` from the files under `benchmarks/published/` (no numbers are typed in by hand).
Each chart has a `-light.svg` and a `-dark.svg` variant; the README picks one with `<picture>` and
`prefers-color-scheme`, and PyPI shows the light one.

```bash
pip install numpy matplotlib
python docs/assets/make_assets.py
```

| File | Shows | Source |
